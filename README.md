
# DroidRun WhatsApp Updates Agent

An intelligent agent built on top of [DroidRun](https://github.com/droidrun/droidrun) that automates sending or monitoring WhatsApp updates using natural language commands and LLM-powered Android automation.

##  Features

- Controls WhatsApp on Android via DroidRun
- LLM-powered decision making (supports OpenAI, Anthropic Claude, Gemini)
- Automates sending updates/messages to WhatsApp contacts or groups
- Runs as an autonomous agent — no manual interaction needed
- Screenshot-based UI understanding — no brittle selectors

##  Prerequisites

- Python 3.11–3.13
- Android device or emulator with ADB enabled
- DroidRun installed
- An LLM API key (OpenAI / Anthropic / Gemini)
