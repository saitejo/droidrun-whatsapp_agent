# 🎬 Demo

The demo for this project was recorded using the **Mobilerun Playground**.

It showcases the agent running fully autonomously — no manual interaction at any point during execution.

## 🔍 What the Demo Shows

- Agent instruction being provided via natural language
- Autonomous interaction with WhatsApp
- Scrolling through and reading unread messages
- Automatic summary generation inside the Notes app
